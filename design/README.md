# Design

Direction A ("Column"), phone first: one centered 720 px column, quiet meta
lines under each story, uppercase topic labels over a hairline, and on phones a
bottom tab bar, 44 px tap targets and 16 px form text.

Standing rules: dark only, true black background, white primary text, dense,
no decorative cards or pills, no grey subtitle lines above sections, no em
dashes, no continuously repainting animations. Tokens live in
`web/src/styles.css`; components use them, never raw hex.

Fonts: Inter Tight and JetBrains Mono, both SIL OFL 1.1. The licenses sit next
to the files in `web/src/fonts/`.
